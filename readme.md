Projeto educacional de um servidor web desenvolvido em C++ com o objetivo de aprofundar conhecimentos em Sistemas Operacionais, Redes de Computadores e programação de sistemas. O projeto explora sockets TCP, protocolo HTTP, concorrência, gerenciamento de memória, I/O não bloqueante e mecanismos de multiplexação de I/O, buscando compreender na prática os fundamentos envolvidos no desenvolvimento de servidores de alto desempenho.
